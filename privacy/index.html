Informationen zur Website und zur OAuth-Anwendung rclone Backup.

Startseite rclone Backup

Website

Diese Website wird über GitHub Pages bereitgestellt. Auf dieser Website werden keine eigenen Analyse-, Tracking- oder Werbedienste eingesetzt und keine eigenen Cookies gesetzt. Beim Aufruf können technisch notwendige Verbindungsdaten durch den Hostinganbieter GitHub verarbeitet werden.

OAuth-Anwendung „rclone Backup“

Die Anwendung dient ausschließlich der privaten Datensicherung in ein vom Nutzer autorisiertes Google-Drive-Konto.

Der Zugriff auf Google Drive erfolgt über die Google-Drive-API. Die Anwendung kann auf Dateien und Ordner zugreifen, soweit dies für das Erstellen, Lesen, Aktualisieren und Löschen der Backup-Daten erforderlich ist.

Speicherung und Weitergabe

OAuth-Zugangsdaten werden lokal auf dem Gerät gespeichert, auf dem rclone konfiguriert wurde. Sie werden nicht über diese Website übertragen und nicht auf einem eigenen Honaro-Software-Server gespeichert.

Backup-Inhalte werden vor der Übertragung durch restic verschlüsselt und anschließend im autorisierten Google-Drive-Konto gespeichert. Es erfolgt keine Weitergabe dieser Daten an Dritte durch Honaro Software.

Widerruf des Zugriffs

Der Zugriff der Anwendung auf Google Drive kann jederzeit in den Sicherheitseinstellungen des verwendeten Google-Kontos widerrufen werden. Dadurch werden bereits vorhandene Backup-Dateien nicht automatisch gelöscht.
